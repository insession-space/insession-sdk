<p class="dep-note">
  No edges between any of them. <code>space</code>, <code>space-state</code>,
  <code>ws-resilient-transport</code>, <code>extension-chat</code>,
  <code>extension-pomodoro</code>, <code>extension-whiteboard</code>, and
  <code>extension-watch-party</code> are each independent — carrying bytes, holding state, and
  assembling extensions are kept apart on purpose, so you can adopt any one alone. Even
  <code>space</code>, the package that ties the state machines together, does not import any of
  them: it only describes the shape (<code>defaultState</code> / <code>reduce</code> / …) they
  already have. Using React? There is no binding package to install: <a href="/examples/react-binding/">one line of your own</a> is the whole hook.
</p>

## Why these

<div class="selling-grid">
  <div>
    <h3>Nothing to install underneath</h3>
    <p>
      The transport and the store have zero runtime dependencies. No framework, no socket
      library, no DOM. That is the point of them, not an accident.
    </p>
  </div>
  <div>
    <h3>Testable without a server</h3>
    <p>
      The store takes plain objects in and hands plain descriptors back, so a full state
      transition is assertable in-process under <code>node --test</code> — no browser, no
      sockets, no wall-clock waits.
    </p>
  </div>
  <div>
    <h3>Shaped by real deploys</h3>
    <p>
      The reconnect behaviour exists because every client drops at the same instant on every
      deploy. Fast path on service restart, jitter so the fleet does not stampede, and a hard
      stop when the server says never again.
    </p>
  </div>
</div>
